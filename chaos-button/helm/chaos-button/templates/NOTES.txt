Ingress is disabled. Access it locally with:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "chaos-button.fullname" . }}-frontend 8080:{{ .Values.service.frontendPort }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "chaos-button.fullname" . }}-backend 8081:{{ .Values.service.backendPort }}

Then browse to http://localhost:8080 (note: the frontend calls the API via
relative "/api" paths, so without an Ingress you'll want to also expose the
backend under the same host/path, e.g. via `kubectl port-forward` plus a
local reverse proxy, or simply enable the Ingress).

Watch the kill log in real time:

Manage resources via the API directly, e.g.:

  curl -X POST http://<host>/api/resources \
