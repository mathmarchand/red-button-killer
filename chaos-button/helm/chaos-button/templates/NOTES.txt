The frontend's nginx serves the UI *and* reverse-proxies "/api/*" to the

{{- if eq .Values.service.frontend.type "LoadBalancer" }}

Get the external IP (may stay <pending> for a minute, or indefinitely on
clusters without a cloud load-balancer, e.g. plain kind/minikube):

  kubectl -n {{ .Release.Namespace }} get svc {{ include "chaos-button.fullname" . }}-frontend -w

Once an EXTERNAL-IP is assigned, browse to:

  http://<EXTERNAL-IP>:{{ .Values.service.frontend.port }}

If EXTERNAL-IP stays <pending> (no cloud LB available), fall back to:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "chaos-button.fullname" . }}-frontend 8080:{{ .Values.service.frontend.port }}

...and browse to http://localhost:8080 - "/api" calls are proxied the
same way either way, since that happens inside the frontend pod.
